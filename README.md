# Prajwal Marketing Portfolio

Next.js portfolio website for public deployment.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Publish publicly (Vercel)

1. Push this repository to GitHub.
2. Sign in to https://vercel.com with GitHub.
3. Click **Add New → Project**.
4. Import this repo and click **Deploy**.
5. Your public URL will be generated automatically.

## Optional custom domain

- In Vercel project: **Settings → Domains**.
- Add your domain and update DNS records shown by Vercel.
